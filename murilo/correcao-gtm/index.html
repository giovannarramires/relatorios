Prof. Murilo Soares · /irrp-inscricao

O código do Google Tag Manager foi colado com defeito

A troca do carregador foi feita, mas o código entrou com uma formatação que quebra o script. Hoje a página de inscrição não registra nenhuma visita nem cadastro. A correção leva 2 minutos.

Conferido em 27/10/2026 · página https://profmurilosoares.com.br/irrp-inscricao/ · contêiner GTM-5PW9JMJT

O que aconteceu

A URL do script foi colada no formato de link do Markdown. Isso acontece quando o código é copiado de um texto formatado (WhatsApp, Notion, ChatGPT, e-mail), que transforma o endereço em link. No código-fonte da página está assim:

j.src=
'[https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f)](https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore\(j,f\));

Os trechos marcados ([, ](…) e as barras \() não fazem parte do código. O navegador encontra um erro de sintaxe e para de ler o script inteiro. Por isso o GTM não carrega, e junto com ele não disparam:

  • o Pixel da Meta (visita e cadastro)
  • o Google Analytics 4
  • o Microsoft Clarity

Os anúncios que levam para essa página ficam sem contar os cadastros enquanto isso não for corrigido.

O que ficou certo: o carregador antigo (api.profmurilosoares.com.br) foi removido e o ID GTM-5PW9JMJT aparece uma vez só. Falta só arrumar a colagem.

O que fazer

  1. Apagar o bloco atual

    No WordPress, no lugar onde o código do GTM foi colado no <head> (plugin de códigos, tema ou Elementor › Código personalizado), apague tudo de <!-- Google Tag Manager --> até <!-- End Google Tag Manager -->.

  2. Colar este código, exatamente como está

    Use o botão para copiar. Não copie passando pelo WhatsApp ou outro app que formata texto.

    <!-- Google Tag Manager -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-5PW9JMJT');</script>
<!-- End Google Tag Manager -->

  3. (Recomendado) Colar o trecho do body

    Logo depois da abertura do <body>. Hoje ele não está na página. Não impede o rastreio, mas é o padrão do Google.

    <!-- Google Tag Manager (noscript) -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-5PW9JMJT"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) -->

  4. Limpar o cache e conferir

    Limpe o cache do site (plugin de cache / CDN). Depois abra a página, clique com o botão direito › Exibir código-fonte e procure (Ctrl+F) por gtm.js. A linha tem que ficar assim, sem colchetes:

    'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);

  5. Avisar a GGD

    Com a troca feita, a gente publica a versão nova do GTM e faz um cadastro de teste para confirmar que tudo dispara uma vez só.

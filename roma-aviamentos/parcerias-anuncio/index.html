Como pedir a autorização das criadoras

Escolhemos quatro reels de parceiras que fizeram muito sucesso no perfil da Roma para impulsionar como anúncio. Para isso o Instagram pede uma autorização de cada criadora — e este guia tem exatamente o que pedir e como explicar para ela.

São só três etapas

Etapa 1Mandar mensagem para cada criadora (a mensagem já está pronta aqui embaixo).
Etapa 2Ela gera um código no post dela e envia de volta — leva menos de um minuto no celular.
Etapa 3Vocês repassam o código para a gente e o anúncio entra no ar.

O passo a passo dela, em detalhe

Se a criadora tiver dificuldade, é este o caminho — pode mandar print desta parte para ela.

  1. Ela abre o post no perfil dela — o mesmo que vocês pediram.
  2. Toca nos ⋯ três pontinhos no canto do post.
  3. Escolhe Parcerias de anúncio no menu que abre.
  4. Toca em Gerar código de anúncio de parceria.
  5. Escolhe por quanto tempo o código vale. Peça para ela escolher o prazo mais longo que aparecer.
  6. Copia o código e manda para vocês. É uma sequência de letras e números — não precisa mandar mais nada junto.
Se ela não encontrar "Parcerias de anúncio"

Tem um segundo caminho, dentro das configurações do Instagram dela:

Configurações e privacidade → Ferramentas e controles de negócios → Conteúdo de marca → Aprovar parceiros comerciais → buscar @romaaviamentos → ativar e marcar a opção de permitir que o parceiro promova as publicações.

Nesse caso ela não precisa mandar código nenhum — é só avisar que liberou.

Três coisas que ajudam a conseguir o sim

  • O conteúdo continua sendo dela. Ninguém copia, regrava nem muda a legenda. O anúncio mostra a publicação original, no perfil dela, com o nome dela.
  • O cupom dela vai junto e passa a circular para muito mais gente — o que também vira venda para ela.
  • Ela ganha alcance de graça. As visualizações, os seguidores e o engajamento que vierem do anúncio entram na conta dela.

Prazo

O ideal é conseguir as autorizações até quarta-feira, 17 de setembro. Assim que os códigos chegarem, a gente já coloca os anúncios no ar.

Não precisa esperar todas responderem — pode ir mandando os códigos conforme chegam, que a gente vai subindo um por um.

Uma dica importante

Se a criadora escolher um prazo curto (30 dias, por exemplo), o anúncio para sozinho quando o código vencer. Por isso vale sempre pedir o prazo mais longo que o Instagram oferecer para ela.
